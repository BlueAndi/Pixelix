# Third-party libraries

This project uses the libraries below. Some are only built for particular
boards or optional features.

| Library | Description | License |
| --- | --- | --- |
| [Arduino](https://github.com/platformio/platform-espressif32) | ESP32 Arduino framework v2.x.x | Apache-2.0 |
| [PlatformIO](https://platformio.org) | Cross-platform build system for embedded software | Apache-2.0 |
| [NeoPixelBus](https://github.com/Makuna/NeoPixelBus) | Controls LED matrices with hardware support (I2S) | LGPL-3.0 |
| [ESP32 HUB75 LED MATRIX PANEL DMA Display](https://github.com/mrcodetastic/ESP32-HUB75-MatrixPanel-DMA) | DMA-driven driver for HUB75 LED matrix panels | MIT |
| [ESPAsyncWebServer](https://github.com/ESP32Async/ESPAsyncWebServer) | Web server | LGPL-3.0 |
| [AsyncTCP](https://github.com/ESP32Async/AsyncTCP) | Asynchronous TCP library for ESP32 | LGPL-3.0 |
| [ArduinoJson](https://arduinojson.org/) | JSON handling | MIT |
| [StreamUtils](https://github.com/bblanchon/ArduinoStreamUtils) | Stream utilities | MIT |
| [Bootstrap](https://getbootstrap.com/) | CSS framework | MIT |
| [Popper.js](https://popper.js.org/) | Positioning engine used by Bootstrap | MIT |
| [Adafruit Unified Sensor Driver](https://github.com/adafruit/Adafruit_Sensor) | Unified sensor abstraction layer | Apache-2.0 |
| [Adafruit BusIO](https://github.com/adafruit/Adafruit_BusIO) | I2C, SPI, and UART abstractions for Adafruit libraries | MIT |
| [RTClib](https://github.com/adafruit/RTClib) | Arduino library for real-time clock modules | MIT |
| [Adafruit DHT sensor library](https://github.com/adafruit/DHT-sensor-library) | Temperature and humidity sensors in the DHT series | MIT |
| [arduino-sht](https://github.com/Sensirion/arduino-sht) | Reads the SHT3x family of temperature and humidity sensors | BSD-3-Clause |
| [TFT_eSPI](https://github.com/Bodmer/TFT_eSPI) | Arduino and PlatformIO display library for TFT driver chips | Mixed: MIT, BSD, FreeBSD |
| [arduinoFFT](https://github.com/kosme/arduinoFFT) | Fast Fourier Transform for Arduino | GPL-3.0 |
| [mufonts](https://github.com/muwerk/mufonts) | Fonts compatible with the Adafruit GFX library | MIT |
| [JSZip](https://github.com/Stuk/jszip) | Creates, reads, and edits ZIP files in JavaScript | MIT |
| [FileSaver.js](https://github.com/eligrey/FileSaver.js) | Saves files on the client side | MIT |
| [PubSubClient3](https://github.com/hmueller01/pubsubclient3) | MQTT publish/subscribe client | MIT |
| [ESP32-PSRamFS](https://github.com/tobozo/ESP32-PsRamFS) | Pseudo-RAM-disk library with VFS compliance | MIT |
| [Dear ImGui](https://github.com/ocornut/imgui) | GUI library used by the native simulator | MIT |
| [PNGdec](https://github.com/bitbank2/PNGdec) | PNG image decoding; only built for boards with PSRAM | Apache-2.0 |
| [libwebp](https://github.com/webmproject/libwebp) | Vendored decoder-only library for static and animated WebP; only built for boards with PSRAM | BSD-3-Clause plus additional patent grant |
