SunrisePlugin

When does the sun rise and set today? The plugin shows both times for the location you enter, as "sunrise / sunset".

You decide how the times look. Click into the time format field and the tag editor opens: choose a preset or compose your own format from hours, minutes and more, add a color, and check the result in the preview.

The format is used for both times and is limited to 16 characters. That is enough for a time with one color, but not for a gradient.

Configuration

Location

The time format string defines how the time is shown. Click into the field to open the tag editor with presets.
