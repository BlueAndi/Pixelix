OpenWeatherPlugin

The plugin shows the current weather condition provided by https://openweathermap.org/.

Additional informations like temperature, humidity, wind speed and UV-index are also available.

On a 64x64 layout the weather forecast of a week will be displayed too.

An API key is required to access the OpenWeather API. Get your API key here.

Configuration

Please enter an integer between 1 and 120 minutes.

Please enter your OpenWeather API key.

Please enter a valid longitude in x.y format, between -180.0 and 180.0 (decimal required).
