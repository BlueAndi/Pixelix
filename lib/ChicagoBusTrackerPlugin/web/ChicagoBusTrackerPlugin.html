ChicagoBusTrackerPlugin

Shows estimated arrival times for a given route+stop+direction

Times are updated at least every 2 minutes

First, you must set an API key and click Update. Then, the lists of routes and stops will populate.

You cannot fetch route or stop IDs from the REST API without an API key.

You can sign up for a CTA Bus Tracker API key from the CTA Developer Portal website

The CTA API limits are quite generous; this plugin will never own its own exhaust your API request quota, even running the maximum number of plugin instances.
