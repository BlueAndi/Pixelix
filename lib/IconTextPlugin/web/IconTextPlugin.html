IconTextPlugin

An icon on the left, your text on the right. A slot without text is skipped.

You decide how the text looks. Click into the text field and the tag editor opens: add colors, gradients, alignment and special characters, and check the result in the preview. Use \n for a line break.

Text that does not fit scrolls. Per plugin instance the icon either scrolls along with the text or stays in place while only the text scrolls.

Pick the icon from the files on the device. The Icons page shows which image file types this device supports.

Text and icon can also be set separately via the REST API. If MQTT is built in and enabled, Home Assistant finds the plugin by MQTT discovery.

Text

The text to show on the display.
The full path of the icon to show, e.g. /configuration/smiley.bmp. Select it from the icons page or enter a path manually. Empty means no icon.
