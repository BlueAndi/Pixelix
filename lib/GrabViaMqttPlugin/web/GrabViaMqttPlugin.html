GrabViaMqttPlugin

This plugin connects to an MQTT server to receive data in JSON format and displays that information on the display. It helps you easily view live updates from devices or services that send data using MQTT.

The filter identifies the value in the JSON payload that you want to display.

Example:

JSON payload:

{ "temperature": 22.5, "humidity": 60 }

The following filter extracts the temperature value from the JSON payload.

{ "temperature": true }

Configuration examples may help to configure.

Format text tags

The following tags are supported in the format text:

  • {#RRGGBB} - Set solid text color (RRGGBB in hex)
  • {lgv #RRGGBB,#RRGGBB,OFFSET,LENGTH} - Set linear vertical gradient text color (RRGGBB in hex, OFFSET in pixels, LENGTH in pixels)
  • {lgh #RRGGBB,#RRGGBB,OFFSET,LENGTH} - Set linear horizontal gradient text color (RRGGBB in hex, OFFSET in pixels, LENGTH in pixels)
  • {stc} - Activate solid text color
  • {lgtc} - Activate linear gradient text color
  • {hl} - Horizontal alignment left
  • {hc} - Horizontal alignment right
  • {hr} - Horizontal alignment center
  • {vt} - Vertical alignment top
  • {vc} - Vertical alignment center
  • {vb} - Vertical alignment bottom
  • {0xCC} - Special character code (CC in hex)

Use for numbers always "%f", independed whether its a integer or floating point number.

In all other cases use "%s".
