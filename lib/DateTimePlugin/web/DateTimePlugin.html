DateTimePlugin

A clock and calendar for your display: the plugin shows the current time and date. Where the layout has room for it, a bar below marks the day of the week.

The layout depends on the display and on the font of the slot, e.g. a larger font leaves no room for the weekday bar. The font is selected per slot on the display page.

You decide how time and date look. Click into the time or date format field and the tag editor opens: choose a preset or compose your own format from hours, minutes, weekday and more, add colors and alignment, and check the result in the preview.

Every plugin instance can have its own time zone, so several instances make a world clock. Without a time zone, the one from the settings is used.

Configuration

Display

The time format string defines how the time is shown. Click into the field to open the tag editor with presets.
The date format string defines how the date is shown. Click into the field to open the tag editor with presets.
If empty, the time zone from settings will be applied.
